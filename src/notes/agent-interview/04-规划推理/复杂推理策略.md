# Agent 面试专题：规划推理 · 复杂推理策略

## Q39: Agent如何处理需要复杂推理的任务？（数学推理、逻辑推理）

### 专业版答案

先把任务转为可验证表达：计算用明确单位和数据类型，逻辑问题用可检查的约束，代码任务用构建与测试。LLM 负责解释、建模和工具选择，数值或形式验证由适合的程序承担。

困难点往往是问题形式化错误、遗漏约束或错误数据，而不是算力不足。验证器与生成器应尽量有独立证据来源，区分“求解正确”和“求解的是不是用户的问题”。

多候选、更多推理预算和自我修复都要在限额内用实验评估。不能把自然语言 confidence 当正确率。

### 白话版答案

先确认题目理解对了，再用适合的工具计算和验证。

### 高级追问与评分点

计算器算得完全正确，但最终报价错误，可能丢了哪些业务约束？
