## Q7: Agent 的记忆系统是如何设计的？

### 专业版答案

把记忆拆成不同职责：当前上下文供模型本轮读取；工作状态记录目标、进度和未决事项；checkpoint 支持 thread/run 恢复；长期 store 保存跨会话需要且获准保留的事实或偏好。

RAG 是取证方式，不等于用户记忆。向量库是索引选择，不是全部记忆架构；结构化偏好可存关系库，原始证据存对象存储。每条长期记录需主体、租户、来源、时间、置信依据和删除策略。

在 LangGraph 中，checkpointer 与 store 对应不同范围，内存实现不提供进程重启后的持久化。[官方 Persistence](https://docs.langchain.com/oss/python/langgraph/persistence)。

### 白话版答案

当前桌面、任务进度和长期档案要分开保存，各有用途。

### 高级追问与评分点

为何不能直接用 thread ID 代替授权？要求解释标识符与访问控制的区别。
