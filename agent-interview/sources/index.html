本次面向高级工程师、架构师与技术负责人，核对日期 2026-09-21。来源中的产品页面会继续变化；核对日期不是保证所有安装版本都支持该功能。题目中的设计方案、数值和评分标准是本题库的练习设计，不是厂商承诺或行业统计。

本次更新范围

  • 校订原八个专题的 50 个文件、72 道题，保留文件路径与题号，统一为专业答案、白话答案、高级追问。
  • 更新主题库的关键原理与全部 C1–C10 代码题要求，保留既有工程内容，增加 D9–D14 六道事故题。
  • 新增 S01–S24 高级场景题，以及 120 分钟、100 分的高级笔试、参考答案和分项评分。
  • 增加 C1/C2/C4/C7 的标准库参考实现及 28 个本地测试，覆盖超时、取消、排队预算、参数验证、调用关联与重复行为。
  • 更新入口、专题计数和 14 天计划。主题库与专题的同名 Q 编号保持各自独立，避免伪造题量增长。

主要旧内容如何处理

旧内容或问题 更新后的考察方式
LangChain 旧链/记忆/AgentExecutor 示例作为默认入口 解释 v1 入口、middleware、LangGraph 分工与迁移验证
AutoGen 的旧 GroupChatManager 代码作为现行新项目教程 明确版本与维护状态，考调度责任和迁移契约
长任务默认换 AutoGPT、多 Agent 必然更强 以同预算评测、任务拆分理由、维护成本决定选型
Agent 天生在线学习、传统软件无状态无学习 按控制流划分，区分记忆更新和模型训练
CoT 必须完全展示、Reflection 一定改善结果 用可观察证据与外部验证，做有预算的消融实验
Docker 即安全、过滤危险词即可阻止注入 执行端授权、隔离配置、数据流与网络出口控制
状态回滚会撤销付款或发信 分开 checkpoint、业务操作账本、幂等与对账
按参数缓存就能避免重复付款 区分参数相同与业务意图相同，覆盖未知提交状态
过时模型价格、无来源提速倍数 使用价目表版本与真实 usage，计算每成功任务成本
重试仅在失败后检查 deadline 单次调用、退避与排队都受预算约束
Recall@k 与“至少命中一个”混淆 区分 Recall、Hit Rate、MRR 与 nDCG
模型 confidence 当概率、SSE 断线必然取消 增加校准要求，明确连接与后台任务的生命周期契约
医疗/金融/法律 demo 直接包装为自主决策 改为证据、专业复核、数据隔离及责任边界题

旧题的历史和论文背景仍可作为延伸学习；已移除大段依赖未定义对象、容易误当作可运行方案的示意代码。可运行实现集中在代码目录，避免文内复制产生漂移。更新前 52 个文件完整保存在 压缩备份 中，可对照和恢复。

验证与维护

参考代码在本机 Python 3.9.6 上运行了 28 个标准库测试，无真实模型调用，不需要凭据；代码语法保持 Python 3.9+ 兼容。这个结果验证教学执行逻辑，不代表厂商 API、生产分布式账本或外部支付系统已完成集成验证。

后续修改建议按三类复查：框架/协议升级时核对官方迁移文档；出现新事故时补失败样本与恢复题；业务目标改变时调整评测和评分。题库持续维护，不再标注“100% 圆满完结”。
