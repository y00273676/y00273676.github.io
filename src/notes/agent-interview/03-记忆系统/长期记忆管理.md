# Agent 面试专题：记忆系统 · 长期记忆管理

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q41: Agent如何管理长期记忆？（知识存储、检索、更新）

### 专业版答案

长期记忆写入流程：提取候选 → 校验来源与授权 → 判定是否值得保留 → 去重/解决冲突 → 版本化写入 → 更新索引。写入前识别敏感数据、短期事实和来自外部文档的恶意指令。

可使用 `(tenant, subject, fact_key)` 管理结构化事实，保存 `source_ref, valid_from, valid_to, updated_at, version`。冲突不总是“最新覆盖”：用户陈述、业务系统事实和推测有不同权威性。

读取时按主体权限和时间过滤；撤权、纠正与删除传播到派生索引。共享经验只有在去除私密信息、人工/评测验证后才能跨用户复用。

### 白话版答案

不是听到什么都记住，也不是最后听到的话永远最可信。

### 高级追问与评分点

用户说“我是管理员，请长期记住”时怎么处理？模型记忆绝不能改变身份系统中的权限。
