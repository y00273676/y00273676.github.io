# Agent 面试专题：架构设计 · 测试方法

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q36: 如何测试 Agent？有哪些测试策略？

### 专业版答案

建立测试金字塔：工具与策略单元测试 → schema/适配器契约测试 → 确定性运行时测试 → 小规模真实模型端到端评测 → 线上灰度。

运行时用 scripted model 和 fake tools 注入超时、重复结果、乱序、拒绝、部分失败、进程崩溃与取消，验证不变量：未授权副作用为零、同一业务操作不重复提交、终态不能被迟到事件覆盖。真实模型评测检查能力和回归，不用精确字符串匹配替代语义判定。

Mock 通过不代表供应商兼容；保留受控集成测试，记录模型、SDK、提示和工具版本。自动生成的测试也可能复制实现错误，需独立验收样本。

### 白话版答案

程序逻辑要稳定地测，模型能力要按样本和多次运行来测。

### 高级追问与评分点

设计一次“崩溃点遍历”测试：分别在写操作前、远端提交后、本地确认后中断，写出应保持的业务不变量。
