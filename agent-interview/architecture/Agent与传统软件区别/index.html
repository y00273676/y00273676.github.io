Q43: Agent 与传统软件的本质区别是什么？

专业版答案

Agent 把一部分控制流交给概率模型，但仍是软件系统。传统软件也可以有状态、学习组件和动态调度；Agent 也可能使用固定流程，不能用“软件死板、Agent 像真人”来区分。

真正增加的是不确定输入解释、动作选择和生成结果。处理方法是缩小不确定边界：模型生成候选，确定性代码执行身份校验、金额计算、事务和验收。记忆写入通常改变外部状态，不等于模型在线训练。

架构评审应问：哪些决策允许近似、错误代价是什么、是否可检测和恢复、模型失效后产品还能提供什么服务。

白话版答案

它仍然是程序，只是某些选择交给了模型，所以需要更明确的边界和验证。

高级追问与评分点

从一个传统审批系统改成 Agent，列出可以替换和不能直接替换的职责，并解释原因。
