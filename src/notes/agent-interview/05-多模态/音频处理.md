# Agent 面试专题：多模态 · 音频处理

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q31: Agent 如何处理音频输入？（语音识别、音频理解）

### 专业版答案

两类架构：ASR → 文本 Agent → TTS，便于逐层控制与审计；原生语音交互更直接处理声音与时序，但需要完整的会话、事件和安全设计。依据延迟、可控性、语言与领域任务评测选择。

关键点包括 VAD、轮次结束判断、打断（barge-in）、回声、说话人区分、流式转写修订和网络恢复。用户打断时不仅停止播放，也要明确是否取消模型生成、排队工具或正在执行的业务操作。

金额、收件人、时间等关键槽位需在执行前核对。录音、转写和声纹属于不同数据，应分别控制访问和保留。不要根据声音情绪推断结果直接触发高风险动作。

### 白话版答案

听懂、轮到谁说话、被打断后停哪些动作，都是语音系统的一部分。

### 高级追问与评分点

用户说“别转了”时转账工具已提交，系统如何回应并查询真实状态？
