> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q33: Agent 在教育场景如何应用？（智能辅导、个性化学习）

### 专业版答案

教育 Agent 应围绕学习目标、提示粒度和可验证反馈设计，而不是直接把答案生成率当成效果。区分讲解、练习生成、过程反馈与正式评分。

学生水平由多次证据估计，避免根据一次回答永久贴标签。教学记忆只保存必要信息，支持更正和删除；课程与知识来源可追溯。涉及未成年用户时，身份、数据与内容政策按产品适用要求落实。

评测看迁移到新题的学习效果、错误讲解率、提示依赖、评分一致性和教师工作量。题目生成器与判题器共享错误时需独立标准答案或人工校准。

### 白话版答案

重点是学生是否学会，而不是系统是否很快把作业写完。

### 高级追问与评分点

使用率上升、测验成绩不变，下一步怎么实验？要求对照设计和明确学习指标。
