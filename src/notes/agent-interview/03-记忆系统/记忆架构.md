# Agent 面试专题：记忆系统 · 记忆架构

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q50: Agent 的记忆系统架构是如何设计的？（短期、长期、工作记忆）

### 专业版答案

推荐分层：

| 数据 | 权威存储 | 更新方式 |
|---|---|---|
| run 状态与预算 | 事务数据库/事件日志 | 条件更新、版本控制 |
| 对话与 checkpoint | 持久状态存储 | 按 thread/run 隔离 |
| 长期事实与偏好 | 关系库或文档库 | 来源校验、冲突处理 |
| 原始证据和产物 | 对象存储 | 不可变版本、访问控制 |
| 检索索引 | 向量/全文/图索引 | 从权威数据构建与失效 |

索引可重建，不应成为唯一事实源。权限和删除事件要传播至缓存、索引及下游产物。摘要只服务上下文，不替代操作账本、审批和金额字段。

### 白话版答案

哪些是事实、哪些是方便查找的副本，要分清楚。

### 高级追问与评分点

向量库丢失后能否恢复？追问权威源、增量同步、删除墓碑和索引版本切换。
