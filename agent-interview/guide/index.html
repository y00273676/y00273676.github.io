本次版本面向 高级工程师 / 架构与技术负责人。基础原理保留，重点考察架构决策、可靠执行、数据权限、评测发布、成本收益与团队责任。各专题保留专业版、白话版，并新增高级追问与评分点。

从这里开始

  1. 24 道高级场景题：每题包含决策依据、追问与评分点。
  2. 120 分钟高级笔试：架构、代码、评测计算、技术决策，附答案与分项评分。
  3. 主题库：基础热身、工程速查、系统设计、Debug、代码、项目深挖与 14 天计划。
  4. 可运行笔试参考代码：Agent loop、重试、并发执行器与 RRF，含 28 个测试。
  5. 更新说明与官方资料：本次修正内容、版本基线和核对来源。

需要对照旧内容时，使用 更新前完整备份。

高级岗位复习优先级

优先级 重点 推荐题目
必备 业务边界、平台职责、执行恢复、审批与隔离 高级 S01–S06
必备 上下文、harness、MCP/A2A、工具规模、多 Agent 高级 S07–S11
必备 评测、模型与框架升级、容量、单位成本 高级 S12–S17
必备 Coding Agent、记忆、安全事故与技术领导力 高级 S18–S24
基础自测 概念、工具、检索、状态和安全 主题库 Q1–Q65
延伸 历史、ReWOO、ToT、Plan-and-Solve、AGI 讨论 专题 Q49/Q57/Q62/Q65/Q72

推荐先口述结论，再写清约束与替代方案，最后补故障路径、验证和责任。准备项目时使用真实指标及失败证据，不把题库中的示例数字当作自己的项目经历。

主题库 Q 与专题 Q 是两套既有编号，同号不表示同一题；内容有交叉，不将它们相加宣称为独立题量。下面按文件实际存放位置统计，已纠正旧版目录中的分类数量。为保留原文件链接，少量跨主题题仍在原位置，题内给出说明。

维护原则

  • 框架、协议和产品事实注明来源及核对日期；本次为 2026-09-21。
  • MCP 传输与授权题固定到 2025-11-25 规范基线；部署时另外核对实际协商版本。
  • 不固化模型价格、榜单名次、未经验证的性能倍数或“百分之百安全”结论。
  • 行业题考察软件系统与责任边界，不把模型输出当作医疗、法律或投资专业判断。
  • 参考代码区分教学实现与生产契约；修改后先验证对应异常路径。
