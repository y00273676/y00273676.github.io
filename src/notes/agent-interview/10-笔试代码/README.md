# 笔试参考代码

对应主题库 C1（只读 Agent loop）、C2（有界重试）、C4（并发执行器）、C7（RRF）以及高级笔试 B1。

- [reference.py](reference.py)：标准库实现，Python 3.9+ 语法兼容，不需要 API key。
- [test_reference.py](test_reference.py)：使用模拟模型和工具验证异常路径。

在题库根目录运行：

```bash
python3 -m unittest discover -s 10-笔试代码 -p 'test_*.py' -v
```

这是验证工程语义的教学实现。消息结构是自定义 adapter contract，不能直接作为 OpenAI 或 LangChain 请求；未包含真实模型适配、生产鉴权、持久账本、费用计量及分布式幂等。C1 只允许预先授权的只读工具，写操作设计见 [[09-高级架构与技术负责人/高级面试题#S03：退款已在支付系统成功，worker 在保存 checkpoint 前崩溃，怎么恢复？]]。

总 deadline 包含排队，单工具 timeout 从真正开始执行算起。协程必须遵守取消、不阻塞事件循环；Python 的取消机制无法强杀任意代码，也不能撤销已经提交的外部业务操作。海量任务应使用有界队列/worker pool，而不是一次为全部输入创建 task。

`completed` 只代表模型返回了符合教学协议的最终文本，业务成功需要独立验收。重复参数限制用于本题防循环，不适用于有进展的状态轮询。`rrf` 对每个来源的重复文档仅按首次出现的原始名次计分；生产输入应先保证排序列表质量。
