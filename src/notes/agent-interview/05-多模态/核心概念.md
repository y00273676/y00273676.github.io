# Agent 面试专题：多模态 · 核心概念

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q15: 什么是多模态 Agent？它有什么优势？

### 专业版答案

多模态 Agent 使用文本、图像、音频或视频作为观察或产物，同时保留动作、状态和权限闭环。多模态模型负责理解，不自动提供安全执行能力。

场景包括文档核验、图表分析、语音交互、界面操作。关键设计是不同模态如何对齐来源、时间戳、坐标、身份及业务对象，以及如何验证最终动作。

评测按感知、决策、执行分层：看错图片、理解错任务、操作错对象应分开计数。保存必要证据与版本，裁剪敏感区域，避免把全屏截图和完整音频无差别写入 trace。

### 白话版答案

它能看和听，但仍要检查是否理解对、是否做对。

### 高级追问与评分点

图片识别率很高，但端到端成功率低，如何设计 trace 定位是哪一层失效？

## Q16: 多模态 Agent 如何处理图像输入？关键技术是什么？

### 专业版答案

应用通常调用支持视觉输入的模型或 OCR/文档解析服务，无需在业务代码里手写“视觉向量与文本向量拼接”。具体输入类型、限制与费用依所用模型而异。

先判断任务需要文字、布局、表格还是视觉语义；按任务选 OCR、版面解析、视觉模型或组合。保留页码、坐标、分辨率、裁剪变换和原始证据引用；输出金额、日期等关键字段后做确定性校验。

遇到低清晰度、遮挡、旋转、相似控件或图像注入，允许请求更好证据或拒绝自动执行。GUI 动作前后重新观察，不能连续依赖过期截图。

### 白话版答案

先确定要看出什么，再选解析方法；认不清时不要猜着执行。

### 高级追问与评分点

发票总额与明细不一致时如何处理？要求区分识别误差、算术错误与原文矛盾。
