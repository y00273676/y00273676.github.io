# Agent 面试专题：架构设计 · 性能优化

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q22: 如何优化 Agent 的响应速度？

### 专业版答案

先拆 trace：排队、上下文/检索、模型首 token、生成、工具等待、审批和重试。分别看交互首响应、端到端完成时间、P95/P99，流式输出主要改善可感知等待。

优化按实测瓶颈选择：减少串行模型往返、批量或程序化处理工具结果、仅并行无依赖工作、缩小上下文、缓存稳定前缀、按任务路由模型。并发受到 RPM/TPM、连接池及下游容量约束，需要背压和每租户配额。

token 减半不保证延迟减半；缓存有查询与校验开销；小模型也可能因多次失败而更慢。以相同成功标准和负载分布做对照。

### 白话版答案

先找到最慢的环节，再优化；更早开始显示文字不等于任务更早完成。

### 高级追问与评分点

P50 不变、P99 翻倍时先查什么？高分答案能讨论排队、重试风暴、长尾工具和大租户挤占。
