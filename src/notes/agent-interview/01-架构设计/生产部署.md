## Q32: 如何在生产环境部署 Agent？需要考虑哪些问题？

### 专业版答案

把同步入口与长任务执行解耦：API 完成鉴权、配额和 run 创建，worker 从持久队列执行，事件流服务提供状态和产物。运行记录、工具操作账本、审批记录、产物分别持久化。

发布单元包括模型配置、提示、工具 schema、策略、检索索引和运行时版本。存量 run 默认固定版本；需要迁移时定义状态 schema 升级和回滚兼容性。worker 用租约和 fencing token 防止过期执行者写回；外部写入仍需幂等与对账。

上线先做离线回归、无副作用 shadow、限流灰度，再扩大流量。回滚配置不等于撤销已经执行的业务动作。

### 白话版答案

长任务应像后台订单一样可查询、可恢复，服务重启也不能把它弄丢。

### 高级追问与评分点

发布时还有两千个等待审批的 run，怎么处理？要说明版本固定、审批有效性、旧 worker 退场和迁移策略。
