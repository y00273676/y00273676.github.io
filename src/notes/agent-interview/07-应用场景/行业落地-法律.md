## Q42: 法律文档 Agent 如何保证证据与专业复核？

### 专业版答案

本题考察辅助系统设计，不提供法律意见。区分合同条款抽取、检索、风险提示和专业判断；每类输出有不同验收与复核责任。

证据必须携带司法辖区、效力/适用时间、文件版本和原文位置。引用存在不代表引用支持结论，模型不能用旧法或其他地区规则直接替代适用材料。合同比较保留原文、修改痕迹与判断理由。

访问控制覆盖客户隔离、检索、缓存和导出；专业复核与签发流程不可由角色 Prompt 代替。评测看引用支持度、漏项、错误归因和关键风险识别，而不是只看文风。

### 白话版答案

先找对地区、时间和版本的材料，再让专业人员检查判断。

### 高级追问与评分点

两份权威材料结论冲突时如何展示和升级，而不是让模型随意选一份？
