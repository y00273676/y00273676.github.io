Q19: 如何解决 Agent 记忆系统的"遗忘"问题？

专业版答案

先区分遗忘来源：历史未检索、被裁剪、摘要遗漏、事实冲突、检索命中但模型未使用。对应记录输入上下文、检索结果和压缩版本，做可重放定位。

关键约束存结构化字段，任务状态有持久化版本，长证据按需读取。检索同时考虑相关性、时效、主体和权限。不要为防遗漏无限塞入历史，更长上下文可能增加冲突和成本。

使用专门的长任务回归：跨摘要保留用户限制、恢复未决审批、辨别旧偏好、停止使用已删除信息。

白话版答案

先查信息是没存、没找到，还是找到了没用对，再解决。

高级追问与评分点

用户偏好已更新，向量检索仍命中旧值，如何阻止旧事实重新写回？
