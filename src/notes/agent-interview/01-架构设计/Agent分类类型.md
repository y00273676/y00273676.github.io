# Agent 面试专题：架构设计 · Agent分类类型

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q45: Agent 有哪些分类类型？各类型的特点和应用场景是什么？

### 专业版答案

分类用于暴露设计约束，没有唯一通用分类法。可从控制流（工作流/动态循环）、执行权限（只读/可逆写/高风险写）、持续时间（交互/长任务）、协作方式（单体/委派/交接）、模态和部署边界描述。

这些维度相互独立。多模态不意味着更自主，多 Agent 不意味着分布式，长期运行也不意味着具备长期记忆。选型时把分类映射到能力：长任务要持久化和恢复，远程工具要身份传播，写操作要授权和提交记录。

### 白话版答案

给系统分类，是为了知道它需要哪些工程保障。

### 高级追问与评分点

为“自动分析工单并提交代码修复”按这些维度分类，说明每个维度改变了什么设计。
