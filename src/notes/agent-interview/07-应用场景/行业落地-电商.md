# Agent 面试专题：应用场景 · 行业落地-电商

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q37: Agent 在电商场景如何应用？（智能推荐、客服、运营）

### 专业版答案

电商 Agent 可负责商品问答、售前推荐、客服与运营草稿。库存、价格、优惠资格、支付和退款由权威业务服务决定，不从模型文本直接落库。

工具应返回报价版本、库存状态和有效期；提交订单时原子重验。缓存按用户权限、渠道、促销和时间失效。写操作设置业务 operation ID，处理超时未知、重复消息及人工接管。

评测除转化率外，还要看错误承诺、重复订单、利润、投诉和退货。自动降价等高影响策略需范围限制、审计、灰度及止损机制。

### 白话版答案

模型可以帮助卖东西，但实际价格、库存和订单必须以业务系统为准。

### 高级追问与评分点

推荐时有货、付款时无货，如何避免错误承诺并恢复用户流程？
