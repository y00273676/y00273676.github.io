# Agent 面试专题：架构设计 · 核心能力

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q44: Agent 的核心能力有哪些？如何衡量Agent的能力水平？

### 专业版答案

能力应按可完成的任务及约束描述：理解与澄清、检索取证、规划和工具选择、执行与恢复、协作、正确终止。长期记忆、多模态和代码执行按需求选配。

衡量时同时限定环境、工具权限、预算和人工帮助。例如“在只读仓库、十分钟预算、无人工补充条件下完成缺陷定位”，比“推理能力强”可验证。分开报告模型裸能力和整个系统的效果；好工具、状态管理和验收器可能比模型升级更重要。

自主性更高不自动代表能力更强：在高风险任务中，正确升级人工可以是成功。

### 白话版答案

能不能在给定时间、权限和预算里把指定工作做好，比会多少技能名称更有意义。

### 高级追问与评分点

如何比较两个 Coding Agent？要求固定环境、测试、预算、人工介入与候选采样数。
