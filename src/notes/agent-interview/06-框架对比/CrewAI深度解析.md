## Q28: CrewAI 的多 Agent 协作机制是什么？如何实现角色分工？

### 专业版答案

CrewAI 用 Agent、Task、Crew 表达协作，Flows 表达状态、事件和执行流程。角色描述帮助分工，但角色标签不创建独立知识、权限或事实正确性。

选择 Crew 时明确任务输入、产物格式、依赖和谁验收；选择 Flow 时明确分支、停止、持久化与恢复。官方 Flow 支持状态持久化，但外部写操作是否重复仍取决于业务幂等和执行边界。

不要假定所有 Agent 自动共享全部记忆或一定按人的组织关系协作。具体功能和默认行为需按安装版本核对。

依据：[CrewAI Flows 文档](https://docs.crewai.com/en/concepts/flows)。

### 白话版答案

角色定义谁做什么，流程定义什么时候做，业务服务决定能不能做。

### 高级追问与评分点

研究员—作者—审核员三角色是否必要？与单 Agent 加确定性引用校验比较同预算效果。
