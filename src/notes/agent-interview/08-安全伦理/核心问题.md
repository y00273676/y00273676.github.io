# Agent 面试专题：安全伦理 · 核心问题

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q14: Agent 有哪些安全风险？如何防范？

### 专业版答案

从资产、主体和信任边界建立威胁模型。主要风险包括提示注入、工具越权、跨租户泄露、数据外传、供应链污染、资源滥用及不安全代码执行。

控制分层：最小数据上下文、工具能力限制、服务端身份与业务授权、审批绑定、沙箱与出口控制、日志脱敏、配额、审计和安全回归。模型拒绝提示是辅助机制，不能成为唯一执行边界。

同时测试攻击成功率和正常任务被误拦率。事故时可以按租户/工具/供应商熔断，并保留脱敏证据用于重放。风险参考 [OWASP Prompt Injection](https://genai.owasp.org/llmrisk/llm01-prompt-injection/) 与 [Excessive Agency](https://genai.owasp.org/llmrisk/llm062025-excessive-agency/)。

### 白话版答案

画清楚数据和权限怎么流动，再把限制放在真正执行的地方。

### 高级追问与评分点

只读工具为何也可能高风险？说明敏感读取、外传组合与查询资源耗尽。
