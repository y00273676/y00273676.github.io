# Agent 面试专题：规划推理 · 核心方法

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q8: Agent 的规划方法有哪些？各有什么优缺点？

### 专业版答案

常见策略包括固定工作流、逐步工具循环、计划—执行—重规划，以及显式候选搜索。零样本和少样本描述提示示例方式，不等同于运行时架构。

选择依据是环境是否变化、步骤依赖、可验证性、失败成本和预算。长任务计划应包含子目标、前置条件、产物、验收和停止条件；计划可以修改，但已执行副作用必须留账。

工程上说“动态重规划”是根据反馈调整步骤；不要与算法课中的 Dynamic Programming（动态规划）混淆。

### 白话版答案

流程固定就按流程做；路径不确定就边做边修计划，并记住已经做过什么。

### 高级追问与评分点

需求中途改变时，哪些任务继续、取消或重做？解释依赖失效与副作用处理。

## Q9: CoT 与推理模型有什么关系？面试是否应要求完整思维链？

### 专业版答案

CoT 是引导中间推理的提示方法，历史上改善了一些推理任务；效果依任务和模型而变。推理模型可以内部使用推理过程，不一定需要额外提示“逐步思考”，也不应把显露完整内部过程作为能力或正确性的判据。

应用需要的是可验证答案、必要的简洁理由、证据和行动记录。计算任务可用解释性的步骤配合代码或求解器校验；审计依赖可观察事件与事实。更长推理不必然更准，也会占用时间和费用。

参考 [OpenAI 推理最佳实践](https://developers.openai.com/api/docs/guides/reasoning-best-practices)。

### 白话版答案

可以要求说明依据和给出可检查的计算，但不能把长篇思考文字当作正确证明。

### 高级追问与评分点

如何在不给用户暴露内部推理的情况下解释一次拒绝退款？说明政策、订单事实、决定和申诉路径。
