# Agent 面试专题：架构设计 · 生命周期

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q46: Agent 的生命周期是什么？从创建到终止的完整流程？

### 专业版答案

生命周期应显式建模，例如：

```text
created → queued → running → waiting_approval → queued → running
running → completed | failed | timed_out
queued / running / waiting_approval → cancelling → cancelled
```

终态变更用条件更新；恢复需要读取 checkpoint、检查租约、校验版本与当前权限。`completed` 必须满足验收标准；`cancelled` 表示停止继续调度，不保证远端已在执行的写操作被撤回。后者需 `unknown` 操作状态和对账。

区分 thread、run、step、attempt 与业务 operation ID。人工审批等待不应永久占用 worker 或数据库事务。

### 白话版答案

把任务当作一张有状态的工单，等待、失败、取消、完成都要有明确记录。

### 高级追问与评分点

取消与工具完成同时发生如何裁决？高分答案分开任务终态和外部操作结果，拒绝用一次状态覆盖丢掉账务事实。
