# Agent 面试专题：架构设计 · 基础概念

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q1: 什么是 AI Agent？和普通 LLM 应用有什么区别？

### 专业版答案

Agent 是让模型根据目标和环境反馈选择下一步动作的系统。工程上应明确模型、控制循环、工具、状态、权限和终止条件；是否存在长期记忆、多个角色或在线学习，并不是必要判据。

普通 LLM 应用也可以多轮、有状态并调用工具；区别应看控制流中有多少决策由模型动态完成。先判断任务是否需要动态路径，再决定使用普通代码、固定 Workflow 或 Agent 节点。不要把“持续运行”误写成“持续更新模型权重”。

### 白话版答案

模型负责提议下一步，程序负责允许它做什么、记录结果，以及什么时候停。

### 高级追问与评分点

给出一个退款流程中必须由代码决定的规则和一个适合交给模型的环节。合格答案要区分意图理解、退款资格、授权和资金执行。

## Q2: Agent 的核心架构组件有哪些？

### 专业版答案

生产系统可分为四层：

- 产品与业务层：目标、验收标准、用户身份、审批政策。
- 运行时层：调度、状态机、上下文组装、取消、预算、checkpoint。
- 能力层：模型、检索、业务工具、沙箱和连接器。
- 治理层：版本、评测、trace、权限、成本和发布。

业务规则由业务服务负责；工具网关执行授权和调用约束；模型输出不能成为权限事实。控制平面管理定义、策略和发布，执行平面处理具体 run，敏感执行凭据按任务范围短期签发。

### 白话版答案

除了能思考，还要有管流程、管权限、记账和验收的系统。

### 高级追问与评分点

画出模型供应商中断时仍必须可用的组件。高分答案包括取消入口、run 查询、审批记录、账务和故障接管。

## Q3: 什么是 ReAct？它与现代工具调用循环是什么关系？

### 专业版答案

ReAct 将推理、动作和环境观察交替组织。工程实现可以是“模型选择动作 → 工具执行 → 返回 observation → 再决策”，无需让模型输出可见的 Thought 文本。

它适合下一步依赖实际反馈的任务；固定流程、批处理和强事务任务未必需要自由循环。工具结果可能过期、错误或被注入，仍需验证。现代推理模型内部推理与应用可审计轨迹是两个概念，审计应记录调用、证据和状态变化。

经典模式是解释控制策略的工具，不是所有 Agent 的必选实现。

### 白话版答案

做一步，看看结果，再决定下一步；看到的结果也可能有问题。

### 高级追问与评分点

让搜索工具连续返回空结果，系统如何改变查询、澄清或停止？只写“再想一遍”不足以得分。
