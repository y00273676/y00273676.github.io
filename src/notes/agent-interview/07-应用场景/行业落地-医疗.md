# Agent 面试专题：应用场景 · 行业落地-医疗

## Q29: 医疗辅助 Agent 如何设计证据、复核与数据边界？

### 专业版答案

本题评审医疗软件系统，不讨论具体诊断方案。先限定用途、用户和责任，例如资料检索或病历整理，不能由模型能力推导出允许自主诊疗。

保持患者匹配、资料来源、文档时间和证据版本；关键字段做原文核对与矛盾提示。专业人员复核机制要体现在工作流与权限中，不能只在答案末尾加一句免责声明。

评测应使用适合用途的专业标注，区分漏项、错误事实、错误关联患者与高风险误导。输入、日志、记忆、模型供应商和导出都需数据边界与保留政策。临床部署要求按适用场景由相关专业团队审查。

### 白话版答案

先明确它辅助哪一步，再确保资料属于对的人、结论有出处、关键决定有人负责。

### 高级追问与评分点

同名患者、旧检查和新记录冲突如何处理？要求展示来源并阻止错误合并。
