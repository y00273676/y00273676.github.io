# Agent 面试专题：安全伦理 · 对齐问题

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q21: 什么是 Agent 对齐？为什么重要？

### 专业版答案

模型训练中的偏好对齐与应用运行时治理不同。应用团队通常不能仅靠修改 Prompt 或模仿 RLHF 描述就改变模型底层对齐。

系统层面应明确用户目标、组织政策、法律/业务约束和冲突处理；将可验证要求转成权限、策略、审批和验收。避免把“用户要求”一律等同于合法授权，也要避免过度拒绝造成任务失败。

评测应包含诚实报告失败、遵守授权范围、接受纠正、正确停止和避免通过修改验收标准获取高分。不能声称达到“100% 安全”，必须说明测试范围与残余风险。

### 白话版答案

目标、规则和真正执行出来的行为要一致，也要能诚实报告做不到。

### 高级追问与评分点

业务 KPI 奖励“自动解决率”时，如何避免 Agent 隐藏失败或阻止用户转人工？
