## Q30: 如何控制 Agent 的运行成本？

### 专业版答案

同时统计模型、工具、检索、沙箱、存储、人工复核和失败返工成本。模型计费由实际 usage 和带生效日期的价目表结算，不在程序里固化某一代模型价格。

```text
每成功任务成本 = 一批任务的总成本 / 该批通过验收的任务数
单位业务净收益 = 业务价值 - 推理与工具成本 - 人工成本 - 预期错误损失
```

缓存输入、未缓存输入、输出和其他计费项按供应商规则计数，避免重复计费。并发分支共享预算，需要原子预留、执行后结算及取消后的尾账处理。价格下降不能代替质量评测，小模型多轮返工可能使总成本更高。

### 白话版答案

算把事情真正办成花了多少钱，还要算失败和人工收尾。

### 高级追问与评分点

成功率从 90% 降到 80%、单次成本降低 20%，能否上线？至少比较成功任务成本、错误严重度、任务价值和人工量；不能只算 token。
