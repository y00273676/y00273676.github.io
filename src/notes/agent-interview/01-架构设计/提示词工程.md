## Q51: Agent 的提示词工程 (Prompt Engineering) 与传统编程有什么不同？

### 专业版答案

Prompt 负责表达目标、约束、工具用法和输出要求；Context Engineering 还包括选择历史、检索证据、工具定义、运行状态和预算内的信息布局。二者都不能替代业务代码中的授权、事务和验证。

采用最小可用指令和明确验收，依据失败样本补充示例；按模型实际能力使用结构化输出和推理配置。不要把“展示完整思维链”作为正确性保证或审计要求，记录简洁决策说明、证据和实际动作即可。

提示、上下文构建器、工具 schema、模型配置作为同一可回归版本管理。外部网页中的命令仍是数据，不因被摘要进上下文而成为可信指令。

### 白话版答案

除了告诉模型怎么做，还要决定这一轮让它看什么；权限仍由程序控制。

### 高级追问与评分点

Prompt 没变但质量下降，列出至少四个检查方向：模型、上下文裁剪、工具/检索数据、政策或流量分布。
