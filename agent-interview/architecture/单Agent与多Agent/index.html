Q52: 单 Agent 与多 Agent 架构 (Multi-Agent) 的区别是什么？何时使用多 Agent？

专业版答案

默认用可观测的单 Agent 建 baseline；当子任务能独立验收、需要隔离上下文或权限、可并行缩短关键路径时，再拆分多个 Agent。

子任务 contract 应带目标、输入证据引用、产物 schema、权限、预算、deadline、取消信号、验收条件和错误类型。主协调器拥有总预算与合并责任。共享事实使用版本化存储，避免广播全部聊天记录。

多 Agent 可能引入重复工作、相关性错误、冲突写入和协作开销，并不天然提高质量或容错。工作目录、凭据和工具策略必须真正隔离，改角色 Prompt 不能形成安全隔离。

白话版答案

能独立交付的活再分出去，每份活都有边界、验收和负责人。

高级追问与评分点

拆分后成功率略升、成本翻倍，如何决定保留？要求同预算消融、失败类型分析及业务净收益。
