# Agent 面试专题：架构设计 · 发展历史

> 校订：2026-09-21。面向高级工程师、架构与技术负责人。保留专题 Q 编号；与主题库 Q 编号分开使用。

## Q49: Agent 演进给今天的架构设计留下了什么经验？

### 专业版答案

将历史作为设计背景：经典 Agent 研究强调感知与行动；LLM 扩展了自然语言规划和工具选择；可运行 demo 之后，工程问题集中在状态、执行环境、评测和权限。

ReAct、计划执行、树搜索等仍有解释价值，但论文名称不是生产架构。接口与框架生命周期会变化，应记录依赖版本、迁移成本和退出方案。不要把某一公司的产品路线写成整个领域必然走向 AGI 的时间表。

复习优先级：运行时与可靠性、业务评测、工具和数据边界优先；年代和旧产品名称只作为延伸。

### 白话版答案

了解历史是为了知道哪些难题一直存在，面试更重要的是解决今天的系统问题。

### 高级追问与评分点

旧项目深度绑定停维框架时，如何在继续交付业务的同时分阶段替换运行时？
